## How to Use This Dossier

1. Read `interview-brief.md` until the core founder thesis can be stated without
   notes.
2. Practice `questions.md` aloud. Do not memorize sentences; memorize the
   claim, proof, and implication.
3. Use `story-bank.md` to select one proof story for each answer. Do not stack
   multiple stories unless the interviewer asks.
4. Check every number against `evidence-ledger.md` before using it.
5. Complete the missing fields in `clinician-discovery.md` before claiming
   recurring pain, purchasing authority, or willingness to pay.
6. Run the pressure drill in `rehearsal.md`.

## Evidence Rule

Use strategic truth, not theatre:

> Claim first, give one or two concrete proofs, state the implication, and stop.

Do not convert conversations into traction, institutional interest into deployment,
or an approved collaboration into a live pilot.
